# Project Overview

This is a project of separate, unrelated, simple websites.

The current implementation target is `clever4ever/`. Read `clever4ever/README.md` and the root `iteration.md` before changing it, and compare visual work with `clever4ever/clever4ever.jpg`. `clevercubed/` is a prior implementation and should be treated only as a donor for established primitives and interaction conventions.

## Project Structure

*   Each website exists in its own folder.
*   Each website folder contains only three files:
    *   `app.js`
    *   `style.css`
    *   `index.html`
*   **Important**: Do not add runtime files beyond those three. Clever 4ever also contains its implementation guide (`README.md`) and visual reference (`clever4ever.jpg`); those are development-only assets and must not be loaded or cached by the runtime app.

## Development Constraints

*   All code must be kept as simple as possible.
*   No external dependencies (CSS frameworks, JavaScript frameworks, etc.) are allowed.
*   Do not include any resources from outside this project in the HTML files.
